# Transcription Bot

Telegram bot which transcribes audio/voice messages/videos into high quality text, using [`faster-whisper`] on CPU, at about 3x realtime speed.

Benchmark for a 464s file (CPU only):

| Model                        | Processing Time (s) | With VAD (s) |
| ---------------------------- | ------------------- | ------------ |
| Transformers Base            | 275                 | -            |
| BetterTransformer w/ Optimum | 193                 | -            |
| faster-whisper               | 166                 | 106          |

## Getting Started

Clone this repo:

```bash
git clone https://github.com/extrange/transcription-bot.git
```

Obtain the Telegram API credentials (`API_ID` and `API_HASH`) for your account from [my.telegram.org][mytelegram]. You will also need a [Replicate][replicate] API token, MinIO/S3 credentials, and an OpenAI-compatible API key.

Create your local configuration from the template:

```bash
cp .env.example .env
```

Only these variables are required:

- `API_ID`, `API_HASH` — Telegram API credentials
- `MY_USERNAME` — your own Telegram username, used for notifications
- `REPLICATE_API_TOKEN` — read directly by the Replicate SDK, not by `Settings`
- `MINIO_ACCESS_KEY`, `MINIO_SECRET_KEY` — MinIO/S3 credentials
- `OPENAI_API_KEY` — OpenAI-compatible API key

Everything else (`SESSION_FILE`, `MINIO_HOST`, `MINIO_BUCKET`, `MODEL_VERSION`, `OPENAI_BASE_URL`, `OPENAI_MODEL_NAME`, `TZ`, and `LOG_LEVEL`) has a sane default in [`settings.py`](src/transcription_bot/settings.py) and only needs to be set in `.env` when the default does not fit. Keep real values in `.env` (ignored by git), not in `compose.yml`.

Pull and run the image published by CI. Compose loads `.env` automatically:

```bash
docker compose pull
docker compose up -d
```

Login credentials will be stored in the path configured by `SESSION_FILE`, which defaults to `credentials/account.session`.

To build the image from this checkout instead, use the local override:

```bash
docker compose -f compose.yml -f compose.build.yml up --build
```

Images are built and published to `ghcr.io/extrange/transcription-bot` by GitHub Actions on pushes to `master` and `v*` tags. If the GHCR package is private, run `docker login ghcr.io` before pulling.

## Development

The development environment is managed with [devenv](https://devenv.sh/):

```bash
devenv shell
```

This provides Python 3.15, `uv`, `ffmpeg`, and the git hooks. Dependencies and the virtualenv are still managed by [`uv`](https://docs.astral.sh/uv/):

```bash
uv sync                                  # install runtime + dev dependencies
uv lock --upgrade                        # update dependencies
```

Inside devenv the virtualenv lives at `.devenv/state/venv`; outside devenv, `uv` uses `.venv`.

Git hooks (ruff, pyright, uv-lock, YAML/Nix checks, and secret scanning) are installed automatically by devenv. `.pre-commit-config.yaml` is generated by devenv and is not tracked.

## Testing

```bash
uv run pytest
uv run coverage run -m pytest && uv run coverage html
uv run ruff check . && uv run ruff format --check . && uv run pyright
```

CI runs the linters, type checker, and tests on every push and pull request, then builds the Docker image.

`MY_USERNAME` is your own Telegram username. It is used to alert you when users use your bot. To obtain it, use [@RawDataBot][rawdatabot] or check your Telegram profile.
